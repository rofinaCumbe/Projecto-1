# Dashboard de Vendas (Projecto 1)

Aplicação interativa de análise e visualização de dados de vendas desenvolvida com Python, Streamlit, Pandas e Plotly.

## 🚀 Funcionalidades

- **Diagnóstico e Análise de Dados**: Processamento e cálculo de KPIs de vendas (nalise_vendas.py).
- **Dashboard Interativo**: Interface gráfica completa desenvolvida em Streamlit (pp.py).
- **Visualizações com Plotly**: Gráficos dinâmicos para acompanhamento de receitas, produtos mais vendidos, categorias e evolução temporal.
- **Entrada Manual de Registos**: Suporte à adição de novos registos na sessão do dashboard.

## 📁 Estrutura do Projeto

- pp.py: Aplicação web interativa com Streamlit e Plotly.
- nalise_vendas.py: Script de terminal para diagnóstico e resumo estatístico.
- dataset.py: Gerador e manipulador de dados de demonstração.
- endas.csv: Conjunto de dados base de vendas.
- equirements.txt: Dependências do projeto.
- iniciar_dashboard.bat: Script para iniciar rapidamente o dashboard.
- executar_analise.bat: Script para executar a análise no terminal.

## 🛠️ Instalação e Execução

1. Clone o repositório:
`ash
git clone https://github.com/rofinaCumbe/Projecto-1.git
cd Projecto-1
`

2. Instale as dependências:
`ash
pip install -r requirements.txt
`

3. Execute o dashboard:
`ash
streamlit run app.py
`
ou clique duas vezes em iniciar_dashboard.bat.
